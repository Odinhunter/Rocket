**⚠ THE ACCEPTANCE BAR WAS MISCALIBRATED, NOT MISSED.** The plan set "aspirant

should have been "no persona names a platform that does not sell its product",

was reaction-time **transfer**: shown a protein BAR, the aspirant asked *"i
