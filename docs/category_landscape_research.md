# Category Landscape Research — candidate categories for Rocket disposition libraries

**Compiled:** 2026-06-07, via live web research (market reports + MBB/firm reports + category consumer sources). ICP frame: **D2C performance marketers advertising on Meta/Instagram in India** (per `icp_and_account_model`).

**Status:** RESEARCH / MENU — *not* a build queue. Categories get built **demand-driven** (a customer/design-partner in that category), one at a time, fully grounded, with Ishan's review on every disposition. See "Reconstruction approach" below.

---

## Scoring dimensions
Each candidate is scored on the four things that actually matter for a Rocket library:
- **Size/growth** — is the category big and growing in India?
- **Meta/D2C ad-intensity** — does the ICP (Meta-heavy D2C marketers) live here?
- **Segmentation richness** — does the category have distinct buyer *mindsets* (→ good dispositions)? This is the most important axis.
- **Voice availability** — can we ground it in real consumer voices (Amazon/Nykaa/Reddit/Quora/YouTube)?

**Reading it:** Skincare is the standout next category — richest *documented* mindset segmentation, highest ad-intensity, adjacent to our health-wellness work, and abundant consumer voice. Fragrances is the most *greenfield* (no dominant player) with genuinely distinct dispositions.

## The recurring-archetype CHECKLIST (not a template)

The most important research finding: **the same ~10-12 attitudinal mindsets recur across every category.** A skincare "Skintellectual," a coffee third-wave obsessive, and a protein macros-lifter are all the *obsessive optimizer* archetype.

| # | Archetype | Shows up as |
|---|---|---|
| 1 | Obsessive optimizer / ingredient-or-spec-loyal | Skintellectual, macros lifter, third-wave coffee, fragrance collector |
| 2 | Clean-label / natural / "clean" identity | clean beauty, clean fragrance, herbal skincare, plant-protein |
| 3 | Value-seeker / dupe-buyer / price-first | Gen-Z dupes, mass haircare, value westernwear |
| 4 | Results-chaser / efficacy-and-proof | "visible results in 90 days," hair-fall switcher |
| 5 | Convenience / efficiency / minimalist | Corporate Glow-Getter, CSMS routine, q-commerce snacker |
| 6 | Lapsed skeptic / "didn't work for me" | recurs in supplements, skincare, hair |
| 7 | Premium aspirant / status-and-identity | premiumization, affordable-luxury fragrance, thrift-as-entry |
| 8 | Traditionalist / Ayurvedic / heritage / food-first | Ayurvedic-clinical hair, attars, dal-rice food-first |
| 9 | Gifter / occasion-driven | fragrance gifting, festive chocolate |
| 10 | Category-entry newcomer | grooming-aware man, first-time pet adopter |
| 11 | Loyalist / habitual / incumbent-locked | brand-loyalist across categories |
| 12 | Hostile rejecter / anti-category | "supplements are a scam," anti-fast-fashion |

**CRITICAL — how to use this (and how NOT to):**
- ✅ **As a completeness checklist** — when building a category, ask "did I cover the obsessive / value / skeptic / convenience / clean-label / lapsed / aspirant mindsets that exist *here*?"
- ❌ **NOT as a generative template.** The archetype *label* is shared; the *behavior is not*. A Skintellectual parsing niacinamide and a macros-lifter counting protein-per-rupee share a label and almost nothing behaviorally. Filling a template per category would reproduce the **homogenization failure** the whole protocol exists to prevent ("every obsessive sounds the same").
- The shared spine **already exists** — it's the 8-dim `DispositionVector`, category-agnostic by design. The recurrence is *not* a cost-saving shortcut. The expensive, quality-determining work — real voices, real SKUs, behavior rules, Ishan's review — is **per-category and unchanged**.

## Reconstruction approach (sequenced, validation-gated)

1. **Validate the core premise FIRST.** Before scaling to any new category, run the parked winner/loser probe on health-wellness: do the agents even *directionally* predict which real ads won? Breadth on an unvalidated base is breadth of *risk*.
2. **Then build demand-driven, one category at a time.** A category gets built when a customer/design-partner needs it. This menu is a *prioritization aid*, not a sprint list. Absent a named partner, **skincare** is the strongest on-spec next build (richest segmentation, highest ad-intensity, wellness-adjacent, abundant voice).
3. **Per category, full grounding + the review gate.** Voice corpus → 5-line gateways (demographic-free) → behavior rules → Ishan reviews every disposition → validate against the public Ad Library winner/loser bench. ~per-category effort, not amortizable to near-zero by the shared spine.
4. **Do NOT mass-generate 9 categories on spec.** It can't be done well in one pass, it's shallow, and it bypasses the human-review gate the protocol mandates.
